# Upwork Job Scoring Rubric

A simple 12-point rubric for deciding whether an Upwork job is worth a Connect and the time required to write a tailored proposal.

## How it works

Score each signal before applying:

| Signal | Points |
|---|---:|
| Payment method verified | 1 |
| Client hire rate above 50% | 1 |
| Client has spent more than $1,000 | 1 |
| Scope is specific enough to estimate | 1 |
| Budget is consistent with scope | 2 |
| Fewer than 15 proposals submitted | 1 |
| Posted within 48 hours | 1 |
| Direct technical fit | 2 |
| Client has left prior reviews | 1 |
| No request for free work | 1 |

**Starting threshold: 7/12.** Calibrate it against your own applications and outcomes.
